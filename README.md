# مصروفي | Masroofi

**فلوسك بيدك، وقرارك بذكاء**

تطبيق أندرويد لإدارة المصاريف الشخصية بالعربية، يدعم الدينار العراقي والدولار كرصيدين منفصلين لا يُجمعان.

## التحميل

[**حمّل آخر نسخة APK**](https://github.com/af317282-dotcom/masroofi/releases/latest/download/masroofi.apk)

أو من [صفحة الإصدارات](https://github.com/af317282-dotcom/masroofi/releases/latest).

يتطلب أندرويد 7.0 أو أحدث.

## المزايا

| | |
|---|---|
| الدخل والمصاريف | تسجيل بالدينار والدولار، وكل عملة برصيد مستقل |
| الادخار | رصيد منفصل، وعملته تُختار مع كل إيداع أو سحب |
| الأهداف | نسبة الإنجاز، والمتبقي، والمطلوب يومياً وشهرياً |
| الميزانيات | حدود شهرية لكل تصنيف مع تنبيهات 70% و 85% و 100% |
| التحليلات | رسوم بيانية وتقارير PDF عربية |
| المحاسب الذكي | يجيب عن أسئلتك بأرقامك أنت |
| الحساب | تسجيل دخول بالبريد أو بحساب غوغل |

## التثبيت

حمّل الملف وافتحه على الهاتف. إذا طلب أندرويد السماح بالتثبيت من هذا المصدر فوافق، ثم أنشئ حساباً داخل التطبيق.
